# Portfolio E5 — BTS SIO SISR

Portfolio personnel destiné à présenter le parcours et les réalisations pour l'épreuve E5.

## Mise en ligne sur GitHub Pages

1. Créer un nouveau repository GitHub.
2. Envoyer tous les fichiers de ce dossier à la racine du repository.
3. Aller dans **Settings → Pages**.
4. Choisir **Deploy from a branch**.
5. Sélectionner la branche `main` et le dossier `/ (root)`.
6. Enregistrer puis attendre la publication.
